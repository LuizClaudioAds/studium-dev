# materiais/

Caixa de entrada do acervo. Aqui ficam os arquivos **brutos** da faculdade —
antes de virarem resumos organizados.

## Como usar

1. Jogue o arquivo na pasta da disciplina (`materiais/<disciplina>/`).
2. Não se preocupe com nome, data ou ordem. Depois a gente arruma.
3. Se não souber onde colocar, use `materiais/_entrada/`.

## O que acontece depois

O conteúdo é lido, resumido e escrito em Markdown dentro de `disciplinas/<disciplina>/`.
O PDF original continua aqui como fonte, e o Markdown é a versão consultável.
