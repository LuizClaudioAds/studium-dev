# Paradigmas de Linguagens de Programação em Python

> **Trilha:** Fundamentos da Computação · **Status:** estruturando

## Em uma frase

Linguagem é ferramenta; paradigma é forma de pensar. A mesma lógica, vista por ângulos diferentes.

## O que ficou

- Paradigma imperativo, funcional e orientado a objetos
- Tipagem, escopo e tempo de vida de variáveis
- Funções como cidadãs de primeira classe, lambdas e closures
- Classes, herança e composição
- Decorators, geradores e expressões idiomáticas de Python

## Por que isso importa depois

Quem só sabe um paradigma usa martelo para tudo. Entender funcional e orientado a objetos me deixa escolher a solução que cabe no problema, não a que eu já sei repetir. E "pensar em Python" — explícito, legível, direto — é um estilo que melhora o código em qualquer linguagem.
