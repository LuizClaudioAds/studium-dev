# Banco de Dados

> **Trilha:** Dados & Web · **Status:** estruturando

## Em uma frase

Dado é o ativo mais caro que um sistema tem — e modelar errado cobra juros para sempre.

## O que ficou

- Modelo relacional: tabelas, chaves e relacionamentos
- SQL: consultas, joins, agregações e subconsultas
- Normalização e integridade
- Transações e propriedades ACID
- Índices, desempenho e modelagem

## Por que isso importa depois

Toda aplicação real guarda, busca e cruza dados. A diferença entre uma consulta que leva 20 ms e uma que derruba o servidor quase nunca está no código da aplicação — está no modelo e nos índices. Saber SQL e modelagem é uma das habilidades mais transferíveis da graduação: vale para backend, dados, produto e até para planilhas bem feitas.
