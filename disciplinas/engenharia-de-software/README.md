# Engenharia de Software

> **Trilha:** Engenharia & Produto · **Status:** estruturando

## Em uma frase

Programar sozinho é artesanato; construir software é engenharia — processo, requisitos, testes e pessoas trabalhando no mesmo código.

## O que ficou

- Ciclo de vida e modelos de processo
- Levantamento e especificação de requisitos
- UML, modelagem e documentação
- Metodologias ágeis e trabalho em equipe
- Testes, versionamento, qualidade e manutenção

## Por que isso importa depois

Código que ninguém entende é dívida, não entrega. Essa disciplina ensina o que separa um projeto que sobrevive de um que morre no segundo mês: requisito claro, escopo controlado, teste e comunicação. É também onde o Git, o code review e a estimativa deixam de ser burocracia e passam a fazer sentido.
