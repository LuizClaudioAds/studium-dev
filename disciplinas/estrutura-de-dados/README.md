# Estrutura de Dados

> **Trilha:** Fundamentos da Computação · **Status:** estruturando

## Em uma frase

Escolher onde guardar o dado é metade da solução — e a diferença entre um programa que voa e um que engasga.

## O que ficou

- Listas, pilhas e filas
- Árvores, grafos e tabelas hash
- Busca e ordenação
- Recursão aplicada a estruturas
- Complexidade: notação Big-O, tempo x espaço

## Por que isso importa depois

Todo framework esconde estruturas de dados. Quando um endpoint começa a demorar, a causa costuma ser uma busca linear onde cabia um índice, ou uma lista onde cabia um conjunto. Entender o custo de cada operação muda a forma de escrever código — e é assunto certo em entrevista técnica. É a disciplina que transforma "funciona" em "funciona bem".
