# Desenvolvimento Web em HTML5, CSS, JavaScript e PHP

> **Trilha:** Dados & Web · **Status:** estruturando

## Em uma frase

A primeira vez em que o código sai do terminal e vira uma página que qualquer pessoa consegue abrir — do HTML semântico ao backend em PHP.

## O que ficou

- HTML5: estrutura, semântica e acessibilidade básica
- CSS: layout, responsividade, Flexbox e Grid
- JavaScript: DOM, eventos e interatividade
- Requisições HTTP e integração frontend/backend
- PHP: formulários, sessões e acesso a banco

## Por que isso importa depois

Essa disciplina é o primeiro **ponta a ponta** de verdade: tela, interação, servidor e dado. Mesmo que hoje eu use outro framework ou outra linguagem, o modelo mental permanece — requisição, resposta, estado, renderização. Saber o que acontece por baixo evita depender de mágica e faz diferença quando algo quebra em produção.
