## Decisões que valem lembrar

1. **Markdown é a fonte da verdade.** O JSON/JS do site é gerado, nunca editado à mão.
2. **Build em Node puro, sem dependências.** O site funciona aberto direto do disco
   (`file://`), o que descarta `fetch()` em tempo de execução.
3. **Saída determinística.** Sem timestamp no arquivo gerado — isso permite o CI
   comparar com `git diff` e falhar quando alguém esquece de regenerar.
4. **Rotas por hash**, não por path. Funciona em `file://` e no Pages sem configurar
   fallback de SPA.
5. **PDF é arquivo, não link.** O leitor acontece no Markdown; os PDFs ficam em
   `materiais/` como fonte.
6. **Deploy por artefato** (`upload-pages-artifact` → `deploy-pages`), publicando
   apenas `preview/`.

## Como rodar

```bash
npm run build          # regera preview/conteudo.js
npx serve preview      # opcional, para testar no celular
```

Abrir `preview/index.html` também funciona.
